# tasks/done

TASKs concluídas com evidência real.

## Critério de entrada

- Build e testes aplicáveis verdes, com saída registrada.
- Revisão (e segurança, quando aplicável) aprovada.
- Relatório do ciclo gerado em `reports/`.
- Documentação e ADRs atualizados quando a decisão mudou.

Sem esses itens, a TASK permanece em `backlog/` ou `blocked`.
