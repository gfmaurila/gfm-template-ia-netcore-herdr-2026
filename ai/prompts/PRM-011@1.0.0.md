# PRM-011@1.0.0 — Decompor em TASKs

```text
Decomponha o PLAN <id> em TASKs usando tasks/TASK-TEMPLATE.md.
Regras: uma TASK = uma unidade verificável; IDs TASK-<AREA>-NNN; incluir contexto,
escopo, não escopo, critérios de aceite, testes esperados, dependências e evidência exigida.
Nenhuma TASK pode exigir mais de um gate. Marque o que depende de aprovação humana.
Saída: lista de TASKs + ordem sugerida de execução.
```
