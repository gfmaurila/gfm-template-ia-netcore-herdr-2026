3. PROBLEMA ENCONTRADO: COMANDOS NAO RECONHECIDOS
======================================================================
Logo apos a instalacao, os comandos abaixo falharam:

hc --version
herdr-app

Motivo confirmado: os caminhos de instalacao estavam registrados no
PATH do usuario, mas nao no PATH da sessao PowerShell em uso.

Diagnostico (somente leitura):

$corePath = "$env:LOCALAPPDATA\Programs\herdr-core"
Get-ChildItem $corePath -Recurse -File | Select-Object FullName

$env:PATH -split ';' | Where-Object { $_ -match 'herdr' }

[Environment]::GetEnvironmentVariable('Path','User') -split ';' |
    Where-Object { $_ -match 'herdr' }

Get-ChildItem "$env:LOCALAPPDATA\Programs" -Directory |
    Where-Object { $_.Name -match 'herdr' } |
    Select-Object FullName

Na maquina examinada, o PATH do usuario continha:
C:\Users\gfmau\AppData\Local\Programs\herdr-app
C:\Users\gfmau\AppData\Local\Programs\herdr-core

======================================================================
4. CORRECAO DO PATH NA SESSAO ATUAL
======================================================================
Primeiro, tente abrir um novo PowerShell. Se o problema persistir e
os diretorios estiverem no PATH do usuario, execute:

$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' +
            [Environment]::GetEnvironmentVariable('Path','User')

Essa operacao atualiza o PATH apenas na sessao atual. Ela nao grava
alteracoes permanentes no registro do Windows.

Valide:

hc --version
Get-Command herdr-app

Resultado confirmado:
- hc --version retornou: hc 0.1.19
- Get-Command herdr-app encontrou herdr-app.exe 0.1.14.0

Se ainda houver falha, confira a existencia dos executaveis:

Test-Path "$env:LOCALAPPDATA\Programs\herdr-core\hc.exe"
Test-Path "$env:LOCALAPPDATA\Programs\herdr-app\herdr-app.exe"

Nao reinstale automaticamente antes de verificar os arquivos e o PATH.
