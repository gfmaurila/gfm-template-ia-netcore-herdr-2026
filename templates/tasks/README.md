# templates/tasks

A fonte canônica do formato de TASK é [`tasks/TASK-TEMPLATE.md`](../../tasks/TASK-TEMPLATE.md).

Motivo: o arquivo é referenciado por `AGENTS.md`, `ai/skills/task-decomposition/` e pelos
prompts de planejamento; duplicá-lo criaria duas versões divergentes.

Novas TASKs devem ser criadas em `tasks/backlog/TASK-<AREA>-NNN-<slug>.md` usando o modelo
canônico.
